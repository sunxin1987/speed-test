结果怎么看

  • 下载 / 上传：刷视频、下载文件看下载；开直播、传大文件看上传。百兆宽带实测应在 90 Mbps 上下。
  • 延迟：打游戏、视频通话最看重它。同城 < 30 ms、跨洲 150 ms 以上都正常。
  • 抖动：延迟的波动幅度，超过 30 ms 通话就容易卡顿、断续。
  • IPv6 未连通：多半是宽带或路由器没开 IPv6，可在光猫 / 路由器后台开启，或向运营商确认。
  • 测速时关掉其他下载、更新和网盘同步，结果才准；Wi-Fi 信号弱会明显拉低无线测速。

把这个网站部署到 GitHub Pages

本页就是一个自包含的 index.html（无后端、无构建步骤），放到 GitHub 仓库开启 Pages 即可上线，IPv4 / IPv6 访问由 GitHub Pages 自动双栈提供。

  1. 在 GitHub 新建一个仓库，例如 speedtest（公开）。
  2. 把本页另存为 index.html，按下方命令推送到仓库根目录。
  3. 仓库 Settings → Pages，Source 选 Deploy from a branch，分支选 main、目录 / (root)，保存。
  4. 约 1 分钟后通过 https://<用户名>.github.io/speedtest/ 访问；绑定自有域名在 Pages 设置里填 CNAME 即可。
git init git add index.html git commit -m "global speed test" git branch -M main git remote add origin https://github.com/<用户名>/speedtest.git git push -u origin main
